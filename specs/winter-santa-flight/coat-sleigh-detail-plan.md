# Coat and sleigh detail implementation plan

**Spec:** `coat-sleigh-detail-spec.md`.

## Architecture and ownership

Use separate garment and sleigh modules with narrow factory boundaries. The garment module owns `santaGarmentGeometry.ts`, its unit test, and integration in `santaModel.ts`/`santaModel.test.ts`. The sleigh factory owns only `santaSleighModel.ts` and its unit test; keep shared model integration outside that factory. Once the sleigh factory is ready, integrate it using the contract below. No other product files, dependency or source asset change is required.

Preserve the public `createSantaTeam(template, santaTemplate)` API, all routes/deer/scene lighting, Santa's seated root `[-.25,.7,0]`, the stronger `[-.10,.06,0]` hand pull and current cap/head motion. Existing renderer-owned Sets remain the sole disposal registry. New factory geometries/materials/textures are registered in those Sets once; factories do not own a second teardown path.

Baseline rendered triangles are 92,668 deer, 41,007 Santa, 11,648 sleigh and 2,496 traces: 147,819 total. Limit the complete new garment factory to 22,000 triangles and the complete sleigh factory to 22,000 triangles, retaining room below the assembled 180,000 limit. Keep material batching and the existing 125-draw/45-rendered-geometry checks. Preserve unrelated dirty work, user development port 4321 and root build output. Production checks use the existing temporary verification copy. No commit, push or deployment.

## Task B: Crafted sleigh factory

**Files:** Create only `santaSleighModel.ts` and `santaSleighModel.test.ts`.

**Factory contract:** `createSantaSleigh(shared: { brass: MeshStandardMaterial; steel: MeshStandardMaterial; leather: MeshStandardMaterial; lantern: MeshStandardMaterial })` returns `{ group: Group; geometries: readonly BufferGeometry[]; materials: readonly Material[]; textures: readonly Texture[] }`. The group is named `santa-sleigh`, positioned `[-4,-.1,0]`, facing +X. Returned resources are only newly owned factory resources; shared input surfaces are borrowed. Put static render meshes directly under this group so the existing parent material batching can combine them. Do not create another renderer, timer, light, scene or disposal method.

- [x] Build a visibly three-dimensional hollow curved wooden hull with closed wall thickness and a broad body bulge, replacing the two flat cookie-like plates. Retain the traditional outline, approximately X -1.9 to 1.9 and outer Z +/-.84. Create layered inset panel faces and rounded/beveled wood edging with genuine depth, plus restrained brass scroll/rivet fittings. Avoid coincident surfaces and excessive ornament. Keep the overall assembly within X -2.10 to 2.10, Z +/-.90 and Y -.50 to 2.0, so Santa remains its tallest part.
- [x] Replace round pipe runners with polished, curved flat metal ribbons with curled noses. Use a stable XY curve frame, about 72 path intervals and eight rounded-rectangle cross-section sides, approximately .12 lateral width and .045 thickness, mirrored about Z +/-.68. Connect them with purposeful supports/crossmembers beneath the floor; no floating rails or unsupported hull. Keep the tow eyes at local `[1.35,.57,+/-.65]`, matching the existing trace starts, and keep the parent coordinate frame unchanged.
- [x] Fit a structured leather seat with a supported cushion top around Y .58, centered near X -.35 and spanning Z +/-.58, so fixed seated thighs indent it slightly. Add a shaped padded back near X -.95, from roughly Y .53 to 1.52, with restrained stitched/tufted channels rather than oval blobs. Interior floor top is Y .08 under boots (their fixed lowest point is about Y .09). Include a footwell and wood joinery without moving Santa.
- [x] Make a folded linen cargo sack around `[-1.37,1.1,.12]`, radii about `[.36,.67,.40]`, with a gathered neck, visible tension folds and tied cord, clear of the seat back. Rebuild both lanterns around `[1.15,1.37,+/-.60]` as amber chambers with thin brass cages and caps, using the borrowed emissive surface and the unchanged existing parent PointLight.
- [x] Prepare deterministic subtle wood grain and sack weave once. Select new painted-wood material around `0x600e16`, roughness .45, metalness 0 and environment intensity about .25; visible interior wood around `0x352319`/roughness .78, padded dark leather around `0x3b2020`/roughness .8 and linen around `0x78634a`/roughness 1. Keep grain low contrast, use small bump relief and avoid metallic paint, plastic glare, purple flat sides or noisy textures. Reuse borrowed brass/steel/leather/lantern where appropriate. No new texture download or runtime dependency.
- [x] Deduplicate returned geometries/materials/textures, sharing primitives within the factory but never across factory instances. Unit-test finite indexed/nonindexed geometry, real panel thickness, flat runner cross-section and symmetry, seat/floor/tow dimensions, material slots/owned maps, resource independence and the 22,000-triangle budget. Do not silently exceed the budget; return a concrete design issue if it cannot support the required result.
