# Hero image compatibility

The installed Windows Playwright WebKit 26.5 fails to decode the actual hero AVIF and independent 16x16 opaque and alpha AVIF fixtures with EncodingError. The same engine decodes a WebP conversion of the hero. Chromium 151 decodes all four data-URL fixtures. This isolates missing AVIF decoder capability in the installed WebKit runtime, rather than network, hydration, image dimensions or alpha corruption. It does not establish a defect in shipping macOS Safari. The current hero nevertheless renders no pumpkin in this supported test environment, so add the same graceful format fallback used by other photographic details.

Export `public/assets/img/halloween/layer-pumpkin.webp` from the active `layer-pumpkin.avif` at identical 1254x1254 dimensions, quality 90 and preserved alpha. Do not use an older pumpkin variant. AVIF remains primary.

In HalloweenArt add pumpkin-source state initialized to the current AVIF URL. Reuse the existing readiness decode effect: if the pumpkin AVIF decode rejects, decode its WebP sibling once, catching that failure as well, then select the WebP URL only if still mounted. Wait for this fallback attempt before marking the scene ready. Other asset failures retain their existing settled-error semantics. The pumpkin definition alone reads the state URL; base and clipped candlelight continue referencing the same image definition. No second loader effect, SVG onError, retry loop or geometry/filter change. Three image definitions remain; the active file inventory grows from seven to eight.

Focused acceptance: Chromium retains AVIF; installed WebKit resolves and decodes WebP; forced AVIF failure selects the same WebP; failure of both still reaches readiness without retry loops or unhandled rejection. Preserve existing reveal, candle, sparks and unmount checks. Asset tests accept the resolved primary/fallback pumpkin URL and verify nonzero decoded dimensions rather than silently accepting a missing image. Visually inspect the formerly missing WebKit hero. No hero animation redesign or dependency change.
