# Lantern draw and stow

## Requirements and diagnosis

On initial Halloween load and when enabling Halloween, the ghost draws its lantern from behind its back with a settling swing. Disabling Halloween stows it behind the back, with inertia, before it becomes fully hidden. Initial original appearance must not flash the lantern. Rapid reversals must continue from the current pose; reduced motion reaches the final state immediately, including a live preference change. Preserve tickle behavior, photographic art, localized glow, normal gentle swing and fallback loading.

The current center clip boundary near x=8.5 and negative-X retreat make the lantern disappear into and emerge from the ghost's center. The correction sends it outward through the ghost's anatomical left side (screen right), with occlusion at the outer edge. The outline ghost has a transparent interior, so DOM ordering alone cannot conceal it behind the body. Retain deliberate lantern-only clipping, existing appearance context and the already implemented reversible travel/inertia lifecycle.

6. On effect cleanup before reversal, snapshot the current computed inertia transform into inline style, detach onfinish, then cancel the old animation. The next effect starts from that snapshot. On normal finish clear the inline transform. Cleanup on unmount cancels without callbacks. No stale animation can overwrite a newer run. New effects must preserve the snapshot before cancellation, matching the existing tickle cancellation discipline.
7. Each presentation effect checks matchMedia prefers-reduced-motion and skips WA when reduced, resetting inertia transform. Register its change listener to cancel any active inertia and clear its inline transform immediately when reduced becomes true; remove listener on cleanup. CSS reduced-motion removes both travel and arc transitions, with the derived present transform already supplying the immediate final pose. Existing CSS also stops inner swing/light/halo as before. Re-enabling motion need not replay the entry; normal idle motion resumes.
