# Lantern draw and stow

## Requirements and diagnosis

On initial Halloween load and when enabling Halloween, the ghost draws its lantern from behind its back with a settling swing. Disabling Halloween stows it behind the back, with inertia, before it becomes fully hidden. Initial original appearance must not flash the lantern. Rapid reversals must continue from the current pose; reduced motion reaches the final state immediately, including a live preference change. Preserve tickle behavior, photographic art, localized glow, normal gentle swing and fallback loading.

Current CSS immediately sets display:none when html appearance becomes original, preventing any exit animation. The ghost is an outline with a transparent interior: moving the lantern below its DOM layer alone cannot hide it behind the body. Use a deliberate occlusion clip on the lantern only. AppearanceContext already exposes the live state; no provider change is needed.

## Exact implementation

1. AnimatedGhost consumes AppearanceContext and compares EAppearance.halloween. Add lantern readiness state, initially false. Extend its existing guarded decode effect: mark ready after AVIF decode; on failure switch to WebP and await one WebP decode before marking ready (catch its failure without retry). Keep active cleanup. Derived `present = ready && appearance === halloween` controls the presentation. This lets initial entry occur with loaded pixels, not while an invisible image is downloading.
2. Remove html-original .lantern display:none. Keep the complete lantern subtree mounted. Inside tickleBody wrap the existing positioned lantern in a stationary clip group, then a travel group (test ID aside-ghost-lantern-travel, data-present true/false). Add scoped clipPath userSpaceOnUse with path `M7.5 -4Q9.5 8 7.5 24H30V-4Z`. It occludes the lantern as it retreats into the ghost's center, including its halo; it must not move with the lantern. Existing body path/eyes remain unchanged.
3. Travel CSS uses transform-box:view-box, transform-origin:0 0. Hidden transform translate(-9px,-.6px); present transform translate(0,0). Transition transform520ms cubic-bezier(.4,0,.2,1). No opacity fade. This native transition reverses continuously on rapid state changes. Preserve existing inner translate(1.2 1.1) scale(.9). Fully hidden rightmost painted edge lies left of the occlusion boundary; static shown artwork clears it.
4. Inside the positioned lantern, add a separate inertia wrapper around the existing lanternSwing group, test ID aside-ghost-lantern-inertia. CSS transform-box:view-box, transform-origin:12.15px 6.1px. Keep normal swing on its existing inner wrapper; inertia must not overwrite it or tickle transforms. Define the idle swing animation on that wrapper regardless of appearance and pause it under original rather than removing it, preserving its current angle across rapid toggles. Reduced motion disables it unconditionally. Otherwise the inner angle would snap independently of the captured outer inertia pose. Use native Element.animate, the same platform API as ghostTickle; no new animation dependency/helper file is necessary.
5. One effect keyed by present animates the inertia wrapper. Read its current computed transform as first keyframe. Entry keyframes: current at0, rotate(-18deg) at.22, rotate(11deg) at.47, rotate(-6deg) at.68, rotate(2deg) at.85, rotate(0deg) at1; duration850ms. Exit: current at0, rotate(12deg) at.2, rotate(-17deg) at.45, rotate(7deg) at.68, rotate(-2deg) at.85, rotate(0deg) at1; duration650ms. Easing ease-out, fill:none. Give animation id lantern-enter/lantern-exit for test identification. Do not run an exit on initial original/initial unready mount: keep a ref recording whether a shown transition has occurred; only hide after prior presentation. No setTimeout completion state.
6. On effect cleanup before reversal, snapshot the current computed inertia transform into inline style, detach onfinish, then cancel the old animation. The next effect starts from that snapshot. On normal finish clear the inline transform. Cleanup on unmount cancels without callbacks. No stale animation can overwrite a newer run. New effects must preserve the snapshot before cancellation, matching the existing tickle cancellation discipline.
7. Each presentation effect checks matchMedia prefers-reduced-motion and skips WA when reduced, resetting inertia transform. Register its change listener to cancel any active inertia and clear its inline transform immediately when reduced becomes true; remove listener on cleanup. CSS reduced-motion removes travel transition, with the derived present transform already supplying the immediate final pose. Existing CSS also stops inner swing/light/halo as before. Re-enabling motion need not replay the entry; normal idle motion resumes.
